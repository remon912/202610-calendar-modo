# 모아 캘린더

회사·개인·쿠폰 일정을 한곳에서 관리하는 모바일 우선 캘린더 웹앱의 프론트엔드 MVP입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 출력하는 로컬 주소를 열어 사용합니다. 프로덕션 빌드는 `npm run build`, 로컬 미리보기는 `npm run preview`로 실행합니다.

## 현재 구현

- 월·주·일·목록 캘린더, 트랙 필터, 일정 추가·수정·삭제
- 할 일 추가·완료·삭제 및 상태 필터
- 쿠폰 수동 등록·사용 완료·삭제
- 다크 모드 선택
- 반응형 모바일 하단 메뉴와 PWA manifest
- 일정·할 일·쿠폰 및 테마를 브라우저 `localStorage`에 저장

## MVP 제한

이 단계는 서버 없이 실행 가능한 프론트엔드입니다. 로그인, 기기 간 동기화, 워크스페이스 공유, 반복 일정, 이미지 OCR, 실제 푸시 발송은 아직 연결되지 않았습니다. 브라우저 알림 권한 요청은 설정 화면에서 가능하지만 백엔드 알림 스케줄러와는 연동되지 않습니다. 데이터는 현재 브라우저에만 저장되므로 브라우저 데이터 삭제 시 함께 삭제됩니다.

다음 단계에서는 명세서의 `feature/setup`에 따라 Neon 스키마·인증과 Vercel API를 연결하고, 데이터 저장소를 서버 API로 교체합니다. 이후 반복 일정·워크스페이스·Claude 쿠폰 인식·Web Push를 기능 단위로 추가합니다.
