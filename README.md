# Mo Do 캘린더

회사·개인·쿠폰 일정과 할 일, 메모, 자기계발(목표 실천·기분 기록)을 한곳에서 관리하는 모바일 우선 캘린더 웹앱입니다.

현재는 **서버 없이 브라우저에서 동작하는 프론트엔드 MVP**입니다. 모든 데이터는 브라우저 `localStorage`에 저장됩니다. 설계 전체는 [3트랙_캘린더_웹앱_기술명세서.md](3트랙_캘린더_웹앱_기술명세서.md)를 참고하세요.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm run lint     # ESLint 검사
```

Node.js 20 이상이 필요합니다. 개발 중 확인은 Node 24 / npm 11 환경에서 했습니다.

## 화면 구성

왼쪽 메뉴(모바일은 하단 탭): **캘린더 · 할 일·메모 · 자기계발 · 쿠폰함 · 설정**

### 캘린더

- 월·주·일·목록 보기
- 상단에 오늘 날짜를 크게 표시하고, 요약 카드(오늘 일정·남은 할 일·쿠폰)를 한 줄로 보여줌
- **일정 추가·수정·삭제**: 시작일·종료일을 지정한 **기간 일정**과 종일·시간 일정을 지원. 삭제는 두 번 눌러 확인
- **날짜 클릭**
  - 날짜 숫자를 누르면 그날의 일정·할 일 목록 팝업이 열림 (목록에서 수정·삭제·추가 가능)
  - 칸의 빈 곳을 누르면 팝업 없이 날짜만 선택됨. 오른쪽(모바일은 아래쪽) "하루" 카드와 "할 일" 카드가 그날 기준으로 바뀜
  - 주·일 보기에서는 위쪽 날짜 머리글을 누르면 목록이 열림
- 화살표 사이 버튼에 선택한 날짜("14일 (수)")를 표시하고, 누르면 오늘로 돌아감. 화살표로 달을 옮기면 그 달 1일이 선택됨
- **목록 보기**: 날짜를 "10.13(화)" 형식으로 표시하고, 화살표를 누르면 일정이 없는 주는 건너뜀
- **캘린더 그룹**: 회사·개인·쿠폰·할 일 칩을 여러 개 켜고 끌 수 있음. 톱니 버튼에서 그룹을 추가하고 이름·색을 바꾸거나 삭제 (삭제한 그룹의 일정은 다른 그룹으로 옮겨짐. 쿠폰·할 일은 고정 그룹)
- 완료한 할 일은 **완료한 날짜**에, 아직 안 한 할 일은 마감일에 표시
- 다가오는 일정: 내일부터 3개

### 할 일·메모

- 할 일 추가(빠른 입력 또는 "마감·반복"), 우선순위, 마감일
- **반복 할 일**: 매일·매주(요일 선택)·매월을 기간으로 지정해 한 번에 생성 (최대 366개). 목록에는 가장 가까운 회차만 표시
- 완료하면 완료 시각을 기록하고, 수정 창에서 **완료일을 바꿀 수 있음** (미래 날짜는 불가)
- 보기: 목록 / 캘린더
- **메모 기록**: 메모장에 저장한 메모를 날짜별 목록이나 캘린더로 모아 봄

### 자기계발

- **목표 실천**: 분야(독서·운동·공부·어학·생활 습관·기타), 실천 요일, 기간을 정하고 날마다 체크
- **오늘의 기분**: 기분 5단계, 감정 태그, 짧은 일기 (하루 한 편)
- 달력 칸에 그날의 기분 이모지와 달성 현황("1/2")을 함께 표시
- 요약: 오늘 실천 · 이번 달 달성률 · 최고 연속 달성 · 이번 달 평균 기분. "이번 달 마음" 통계

### 쿠폰함 · 설정

- 쿠폰 수동 등록, 사용 완료, 만료 탭, D-day 표시
- 라이트·다크 테마, 브라우저 알림 권한

### 공통 기능

- **앱 전체 검색** (`Ctrl+K` / `⌘K`, 모바일은 헤더의 돋보기): 일정·할 일·메모·자기계발 목표·기분 기록을 한 번에 검색. 결과를 누르면 해당 날짜의 달로 이동해 그날 목록을 엶 (메모는 메모 기록 캘린더 + 메모장)
- **플로팅 메모장**: 데스크톱은 오른쪽 아래 버튼, 모바일은 헤더 아이콘. 드래그로 위치 이동, 날짜 지정, 색상, 저장·수정·삭제
- **날짜 선택기**: 연도·월을 버튼으로 바로 고르는 앱 전용 달력 (모든 날짜 입력에 적용)
- 반응형 레이아웃(데스크톱 사이드바 / 모바일 하단 탭), PWA manifest

## 데이터 저장

모든 데이터는 브라우저 `localStorage`에 저장되므로 **기기 간 동기화가 되지 않고**, 브라우저 데이터를 지우면 함께 삭제됩니다.

| 키 | 내용 |
| --- | --- |
| `moa-calendar-events` | 일정 (`start`, `endDate`, `allDay`, `startTime`, `endTime`, `track` 등) |
| `moa-calendar-todos` | 할 일 (`dueDate`, `done`, `doneAt`, 반복 시 `seriesId`·`repeat`) |
| `moa-calendar-memos` | 메모 (`date`, `title`, `body`, `color`) |
| `moa-calendar-tracks` / `moa-calendar-hidden-tracks` | 캘린더 그룹 정의 / 꺼둔 그룹 |
| `moa-calendar-growth` | 자기계발 목표와 날짜별 체크 기록 |
| `moa-calendar-diaries` | 기분 기록 |
| `moa-calendar-theme`, `moa-calendar-memo-position` | 테마, 메모장 위치 |

저장 키의 `moa-` 접두사는 이름을 바꾸기 전에 정한 것입니다. 기존 데이터를 유지하려고 그대로 두었습니다.

## 폴더 구조

```text
src/
├── App.jsx               # 앱 셸, 캘린더 화면, 일정 편집 창, 쿠폰함·설정
├── pages/                # TodosPage(할 일·메모), GrowthPage(자기계발)
├── components/           # DatePicker, SearchPalette, MemoPad, DayAgenda, TrackManager 등
├── lib/                  # 날짜·일정·할 일·메모·자기계발·그룹 계산과 저장 헬퍼
└── styles.css            # 디자인 토큰과 전체 스타일 (라이트·다크)
api/                      # Vercel Functions 공통 모듈과 /api/health (백엔드 준비용)
db/schema.sql             # Neon PostgreSQL 스키마 (명세서 5장)
```
